# قائمة تجهيز الطلبات — تطبيق خاص لسلة

موقع يعرض طلبات متجرك في سلة (بانتظار المراجعة / قيد التنفيذ) **لحظيًا** (بدون قاعدة بيانات)، مجمّعة بثلاث طرق:

1. **ملخص الأصناف الكلي** — كم قطعة تحتاج تجهّز من كل صنف/خيار عبر كل الطلبات
2. **طلبات متطابقة (Cluster)** — طلبات لها نفس المحتوى بالضبط، تُجهّز كدفعة واحدة
3. **طلبات فريدة** — كل طلب لا يوجد له مثيل، يُعرض لوحده

---

## 1) الحصول على Access Token من سلة

1. ادخل بوابة الشركاء: https://portal.salla.partners
2. أنشئ تطبيق جديد → اختر نوع **Private App** (تطبيق خاص) واربطه مباشرة بمتجرك
3. من إعدادات التطبيق، فعّل الصلاحيات (Scopes) التالية على الأقل:
   - `orders.read` (قراءة الطلبات)
4. انسخ الـ **Access Token** الذي يعطيك إياه سلة بعد الربط

> ملاحظة: التوكن في التطبيق الخاص لا ينتهي بنفس آلية OAuth العادية للتطبيقات العامة، لكن راجع صفحة التطبيق في البوابة للتأكد من صلاحيته وتجديده عند الحاجة.

---

## 2) التشغيل محليًا (اختياري، للتجربة قبل النشر)

```bash
cd salla-prep-app
cp .env.example .env
# افتح .env وضع التوكن الفعلي في SALLA_ACCESS_TOKEN
npm install
npm start
```

افتح المتصفح على `http://localhost:3000`

---

## 3) النشر على Vercel (موصى به — بدون توقف/نوم مزعج)

المشروع فيه ملف `vercel.json` جاهز يخليه يشتغل مباشرة على Vercel بدون أي تعديل إضافي.

**الخطوات:**

1. **ارفع الكود على GitHub** (لو ما رفعته قبل):
   - سوّي حساب على github.com إن لم يكن عندك
   - أنشئ Repository جديد (خاص/Private) باسم `salla-prep-app`
   - بصفحة الريبو الفاضية اضغط **"uploading an existing file"**، اسحب كل ملفات المشروع وأفلتها، ثم **Commit changes**

2. **ادخل vercel.com** وسجّل دخول **بحساب GitHub** مباشرة (زر "Continue with GitHub")

3. اضغط **"Add New..."** → **"Project"**

4. من قائمة الريبوهات، اختر `salla-prep-app` واضغط **"Import"**

5. Vercel يكتشف الإعدادات تلقائيًا من `vercel.json` — لا تحتاج تغيّر شي في Build/Output settings

6. قبل الضغط على Deploy، افتح قسم **"Environment Variables"** وأضف:
   - `SALLA_ACCESS_TOKEN` = التوكن الفعلي
   - `SITE_USERNAME` = اسم مستخدم من اختيارك
   - `SITE_PASSWORD` = كلمة مرور قوية من اختيارك

7. اضغط **"Deploy"** — بعد أقل من دقيقة يعطيك رابط جاهز مثل:
   `https://salla-prep-app.vercel.app`

**تحديث الموقع لاحقًا:** أي تعديل على الكود، ترفعه لنفس الريبو على GitHub (نفس زر uploading files)، وVercel ينشر النسخة الجديدة تلقائيًا خلال ثوانٍ.

---

## 3-ب) النشر على Replit (بديل)



1. ادخل https://replit.com وأنشئ **Repl جديد** من نوع **Node.js**
2. ارفع كل ملفات المشروع (اسحبها وأفلتها، أو استخدم زر Upload folder)
3. من التبويب الجانبي، افتح **Secrets** (🔒) وأضف:
   - المفتاح: `SALLA_ACCESS_TOKEN` — القيمة: التوكن الذي نسخته
   - المفتاح: `SITE_USERNAME` — القيمة: اسم مستخدم من اختيارك (مثلاً `admin`)
   - المفتاح: `SITE_PASSWORD` — القيمة: كلمة مرور قوية من اختيارك

   بدون هذين المفتاحين الأخيرين الموقع **لن يفتح لأي أحد إطلاقًا**، بما فيك أنت — هذا مقصود حتى لا ينفتح الموقع بالخطأ بدون حماية.
4. اضغط زر **Run** — Replit تلقائيًا تنفذ `npm install` ثم `npm start`
5. سيظهر لك رابط عام (Webview URL) في أعلى الشاشة — هذا هو رابط موقعك

**لضمان بقاء الموقع شغّال باستمرار** (بدون نوم بعد فترة خمول)، فعّل خاصية **"Always On"** أو **"Deployments"** من إعدادات الـ Repl (تتطلب خطة Replit مدفوعة أو Core).

## ملاحظات مهمة

- **الأداء**: لكل طلب يتم جلب تفاصيله الكاملة من سلة (لأن قائمة الطلبات العامة لا تحتوي على الخيارات/SKU بدقة). لو كان عندك مئات الطلبات في نفس الحالة، التحميل قد يأخذ بضع ثوانٍ — هذا طبيعي ومتوقع بسبب عدد الطلبات، مش خطأ.
- تقدر تتحكم بالحد الأقصى لعدد الطلبات المجلوبة عبر `?max=300` في رابط الـ API (مضبوط افتراضيًا 300).
- **لا يوجد حفظ للبيانات** — كل مرة تفتح الصفحة أو تضغط "تحديث" يتم الجلب من سلة مباشرة (حسب طلبك).
- هذا الإصدار **لا يشمل** تحديث الحالة أو طباعة البوليصات (اتفقنا نأجلها) — فقط عرض وتجميع.

## الحماية من الدخول غير المصرح به

الموقع محمي بالكامل بـ **Basic Auth**: أي زيارة للرابط (الصفحة أو أي طلب API) تطلب اسم مستخدم وكلمة مرور أولاً، ولن تُعرض أي بيانات بدونهما. المتصفح يحفظ بيانات الدخول بعد أول مرة تدخلها، فما تحتاج تكتبها كل مرة على نفس الجهاز.

**لمشاركة الموقع مع موظف تجهيز مثلاً**: أعطه رابط الموقع + اسم المستخدم وكلمة المرور نفسها (أو غيّرها لكل شخص لاحقًا لو احتجت صلاحيات منفصلة — يتطلب تعديل بسيط بالكود).

**لتغيير كلمة المرور لاحقًا**: عدّل قيمة `SITE_PASSWORD` في Secrets على Replit، ثم أعد تشغيل الـ Repl.
